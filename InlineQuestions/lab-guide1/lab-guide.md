## L1 — VMware Theoretical Assessment

### Estimated duration: 35 minutes

### Format

This is a **theory-only** assessment delivered through the CloudLabs question portal. **No live lab environment** is provisioned — VMware vSphere cannot be hosted in CloudLabs cloud due to licensing and hardware-virtualization constraints. All questions are conceptual or scenario-driven and stand alone.

### Capability Area 1: Theoretical Knowledge (100% weight)

This single capability area tests depth and breadth of VMware vSphere knowledge across architecture, HA/DRS, vMotion, storage, networking, vSAN, NSX, hybrid cloud (VMC/AVS), migration, and operational troubleshooting.

### Difficulty mix

| Topic | Questions | Mix |
|---|---|---|
| vSphere architecture (ESXi, vCenter, VM, datastore) | 4 | Foundational 2 + Practitioner 2 |
| vMotion / Storage vMotion | 2 | Foundational 1 + Practitioner 1 |
| HA + DRS | 3 | Foundational 1 + Practitioner 1 + Expert 1 |
| Distributed switches (VDS) / networking | 2 | Practitioner 2 |
| VMFS vs NFS / datastores | 2 | Foundational 1 + Practitioner 1 |
| Snapshots vs backups | 2 | Foundational 1 + Practitioner 1 |
| Resource pools / shares-limits-reservations | 2 | Practitioner 1 + Expert 1 |
| vSAN basics | 2 | Foundational 1 + Practitioner 1 |
| NSX overview | 1 | Practitioner 1 |
| VMware Cloud on AWS / Azure VMware Solution | 2 | Practitioner 1 + Expert 1 |
| P2V / V2V migration concepts | 1 | Practitioner 1 |
| Operational scenarios (host failure, VM unresponsive, snapshot growth) | 2 | Practitioner 1 + Expert 1 |
| **Total** | **25** | |

### How this is graded

- **MCQ (Single / Multiple Choice / True-False)**: auto-graded by the portal. Multiple Choice uses partial credit (1 pt all correct; 0.5 if n-1 of n correct; 0 if any wrong selection).
- **Short-Answer**: SME rubric-graded within 24 hours after submission (0–3 pts: 3 = complete + accurate, 2 = mostly, 1 = partial, 0 = wrong/blank).
- **Pass criteria**: 60% overall.
