## Question
22. A McKinsey client wants to replace 30 aging UNIX systems running custom Java applications with a single zLinux LPAR for cost and consolidation. Which IBM tool / pattern is most relevant for this consolidation play?

## Options
Option 1: IBM Db2 Data Sharing
Option 2: IBM LinuxONE / zLinux consolidation - replaces many discrete Linux/UNIX systems with z/VM guests on IFLs at lower TCO due to per-IFL pricing
Option 3: IBM Cloud Pak for Data
Option 4: IBM Wazi sandbox

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. Consolidating dozens of x86/UNIX workloads onto IFLs under z/VM is the canonical LinuxONE / zLinux value proposition: dense virtualization, lower TCO via consolidation, integrated RAS.

## Incorrect Answer Feedback
Db2 Data Sharing is a specific DB2-on-z/OS feature. Cloud Pak for Data is a multi-cloud data platform. Wazi is a developer sandbox for z/OS, not Linux consolidation.
