## Question
6. Which z/VM construct allows live relocation of a running Linux guest from one z/VM member to another within the same Single System Image (SSI) cluster?

## Options
Option 1: VMRELOCATE (Live Guest Relocation)
Option 2: vMotion
Option 3: zfcpdump
Option 4: zipl

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. VMRELOCATE is the z/VM CP command that performs Live Guest Relocation across SSI members, the z/VM equivalent of vMotion.

## Incorrect Answer Feedback
vMotion is VMware. zfcpdump captures dumps from FCP-attached storage. zipl is the s390x bootloader.
