## Question
4. Which statement about z/VM is correct?

## Options
Option 1: z/VM is the IBM operating system for mainframe transaction processing
Option 2: z/VM is a Type-1 hypervisor for IBM Z that hosts Linux (and other) guests; it itself runs in an LPAR
Option 3: z/VM is an emulator that lets you run mainframe workloads on x86 servers
Option 4: z/VM is a deprecated product replaced by KVM on IBM Z

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. z/VM is IBM's mainframe hypervisor running inside an LPAR, hosting Linux guests (and z/OS, z/TPF, z/VSE). It provides high-density virtualization with fast cloning (NSS / DCSS) and live guest relocation across SSI clusters.

## Incorrect Answer Feedback
Transaction processing is CICS/IMS on z/OS, not z/VM. z/VM does not run on x86. KVM on Z exists alongside z/VM but does not replace it.
