## Question
20. Which workload pattern is most architecturally well-suited to zLinux on IBM Z (vs. x86 Linux)?

## Options
Option 1: Embarrassingly parallel HPC simulations across thousands of cheap commodity nodes
Option 2: Large-memory, high-I/O, transactional workloads requiring vertical scale, high availability, and pervasive encryption (e.g., Db2 LUW, Oracle DB consolidations, large Java heaps)
Option 3: Edge IoT workloads with very small memory footprints
Option 4: GPU-accelerated machine learning training

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. IBM Z excels at vertical scale-up, deep I/O parallelism, RAS, and pervasive encryption. Common targets: Db2 LUW consolidation, large JVM heaps, MQ/CICS/Db2 hub workloads, regulated workloads needing FIPS-certified crypto offload.

## Incorrect Answer Feedback
HPC scale-out, low-power IoT, and GPU ML training are x86/ARM/GPU strengths, not Z's sweet spot.
