## Question
1. Which two Linux distributions are officially supported by IBM for production deployment on IBM Z (s390x architecture)?

## Options
Option 1: Red Hat Enterprise Linux and SUSE Linux Enterprise Server
Option 2: Ubuntu Server and Debian
Option 3: Oracle Linux and Amazon Linux
Option 4: Rocky Linux and AlmaLinux

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. RHEL and SLES are the two distributions officially supported on IBM Z, with full support contracts, hardware certification, and pervasive encryption integration.

## Incorrect Answer Feedback
Ubuntu has community s390x builds and limited Canonical support but is not the standard IBM-Z production stack. Oracle Linux, Amazon Linux, Rocky, and AlmaLinux do not have first-class IBM Z support.
