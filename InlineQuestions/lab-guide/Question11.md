## Question
11. Which is the default journaled filesystem on AIX 7.x?

## Options
Option 1: JFS (the original 32-bit JFS)
Option 2: JFS2 (Enhanced Journaled File System)
Option 3: ext4
Option 4: ZFS

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. JFS2 is the default and recommended filesystem on AIX 5.2+. It supports 64-bit, large files (>1 TB), online resize, and snapshots.

## Incorrect Answer Feedback
The original JFS is legacy. ext4 is Linux. ZFS is Solaris/illumos (and Linux ports), not AIX.
