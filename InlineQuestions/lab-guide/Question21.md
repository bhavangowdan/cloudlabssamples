## Question
21. What is PowerHA SystemMirror (formerly HACMP)?

## Options
Option 1: A real-time backup product for AIX
Option 2: A clustering / HA solution for AIX (and Linux on POWER) that monitors resources and fails them over between cluster nodes on failure
Option 3: A network monitoring tool
Option 4: A POWER firmware feature

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. PowerHA SystemMirror is IBM's HA cluster product for AIX/POWER. It groups resources (VG, application start/stop scripts, IP labels) into resource groups and fails them over between nodes when a fault is detected.

## Incorrect Answer Feedback
PowerHA is not a backup tool. It is software, not POWER firmware.
