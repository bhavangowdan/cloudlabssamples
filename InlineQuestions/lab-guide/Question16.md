## Question
16. What is SMIT (smitty) on AIX?

## Options
Option 1: A package manager analogous to yum / apt
Option 2: A menu-driven system management interface that translates menu choices into command-line invocations
Option 3: A dump capture tool
Option 4: A log analysis tool

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. SMIT (System Management Interface Tool) is AIX's menu-driven admin interface. It is famous for showing the underlying command (F6 / smit.script) so admins can capture the equivalent CLI form for scripting.

## Incorrect Answer Feedback
AIX package management uses installp / lslpp / lpp_source. SMIT is interactive admin, not a dump or log tool.
