## Question
23. What is NIM (Network Install Manager) used for in AIX environments?

## Options
Option 1: A graphical AIX installer for laptops
Option 2: A central management server that installs, patches, and recovers AIX clients over the network using SPOT, lpp_source, mksysb, and other resource types
Option 3: A monitoring product
Option 4: A network packet capture tool

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. NIM enables centralized network-based AIX deployment and lifecycle management. Resource types include lpp_source (filesets), SPOT (Shared Product Object Tree), mksysb (image), and bosinst data. Standard for managing fleets of AIX/POWER systems.

## Incorrect Answer Feedback
NIM is server-side fleet management, not a desktop installer. It is not a monitoring or packet-capture tool.
