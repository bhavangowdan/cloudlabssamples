## Question
9. What does Live Partition Mobility (LPM) do in a PowerVM environment?

## Options
Option 1: Migrates a running AIX or Linux LPAR from one POWER frame to another with no application downtime
Option 2: Migrates a WPAR between LPARs
Option 3: Performs a cold backup of an LPAR
Option 4: Reboots an LPAR with retained state

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. LPM is the PowerVM equivalent of vMotion — live migration of a running LPAR across frames, useful for rolling firmware upgrades, planned maintenance, and rebalancing.

## Incorrect Answer Feedback
WPAR mobility is Live Application Mobility (LAM). Backups and reboots are unrelated.
