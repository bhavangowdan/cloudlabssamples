## Question
4. What does JES (Job Entry Subsystem) do on z/OS?

## Options
Option 1: Stores datasets on DASD
Option 2: Reads jobs into the system, schedules them on initiators, and manages their output
Option 3: Manages security
Option 4: Provides the TSO terminal interface

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. JES (JES2 or JES3) is the job entry subsystem — it queues jobs, dispatches them to initiators based on class/priority, captures SYSOUT, and routes output to printers / spool / external readers.

## Incorrect Answer Feedback
DASD storage is a data access subsystem (DFSMS). Security is RACF/ACF2/Top Secret via SAF. TSO is the interactive shell.
