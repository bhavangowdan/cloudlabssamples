## Question
18. What is CICS (Customer Information Control System) at a high level?

## Options
Option 1: A relational database
Option 2: A high-performance online transaction processing (OLTP) middleware that hosts business transaction programs (typically COBOL or PL/I) accessed via 3270 terminals, web services, or APIs
Option 3: A backup product
Option 4: A z/OS console

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. CICS is the canonical mainframe OLTP platform. It manages transactions (units of work), terminals / sessions, programs, and integrations with DB2 / IMS / MQ. Many large enterprises run thousands of TPS on CICS.

## Incorrect Answer Feedback
CICS is not a database (DB2 / IMS are). It is not a backup tool or console.
