## Question
5. Which is a meaningful operational difference between JES2 and JES3?

## Options
Option 1: JES2 is per-image (each z/OS image has its own JES2 spool); JES3 has a global view across a JES3 complex with a single global processor scheduling jobs across all members
Option 2: JES2 supports SDSF; JES3 does not
Option 3: JES3 is open source; JES2 is proprietary
Option 4: JES3 is the modern default

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. JES2 maintains its own spool per z/OS image with cross-system coordination optional (MAS — Multi-Access Spool). JES3 has a single global processor that schedules across all members. JES3 was withdrawn from new sales (z/OS 2.5 announced its sunset); JES2 is now the default and only forward path.

## Incorrect Answer Feedback
SDSF works with both. Neither is open source. JES3 is being retired, not the modern default.
