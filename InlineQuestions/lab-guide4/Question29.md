## Question
29. A McKinsey client wants to expose existing CICS COBOL transactions as REST / JSON APIs to mobile and partner channels WITHOUT rewriting the COBOL. Which IBM product is most directly purpose-built for this?

## Options
Option 1: z/OS Connect Enterprise Edition
Option 2: WebSphere Application Server for z/OS only
Option 3: IBM MQ
Option 4: TWS

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. z/OS Connect EE provides REST/JSON API enablement of mainframe assets (CICS, IMS, DB2, batch). It generates Swagger/OpenAPI definitions and routes API calls to existing COBOL programs without code changes — the canonical "API economy" pattern for mainframe modernization.

## Incorrect Answer Feedback
WebSphere AS for z/OS hosts Java apps but is not the primary REST-on-mainframe gateway. MQ is messaging. TWS is workload scheduler.
