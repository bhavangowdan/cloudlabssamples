## Question
24. What is SDSF on z/OS used for?

## Options
Option 1: To define security policies
Option 2: To monitor active jobs / output queues / SYSLOG / system commands and provide an operations-grade view of JES2 (and modern JES3 environments)
Option 3: To compile COBOL code
Option 4: To manage tape libraries

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. SDSF (System Display and Search Facility) is the standard ISPF panel set for operations: DA (active address spaces), JES2/3 input/output queues, ULOG (user-issued commands), SYSLOG, SR (system requests), etc.

## Incorrect Answer Feedback
Security is RACF. Compilation is HLASM/COBOL. Tape libraries are managed by DFSMS-RMM or HSM.
