## Question
15. Inside ISPF, a sysprog enters "=3.4" on the primary command line. What does this do?

## Options
Option 1: Switch to log option 3, sub-option 4
Option 2: Jump to the Data Set List Utility (Option 3.4 — the dataset browser used to list, edit, browse, allocate, and delete datasets)
Option 3: Set screen background to dark mode
Option 4: Reduce font size to 4-point

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. =3.4 is the standard fast-path to the ISPF Data Set List Utility (DSLIST) — one of the most-used panels for browsing, editing, and managing dataset members.

## Incorrect Answer Feedback
The "=" prefix is the ISPF shortcut to navigate panel tree directly. 3.4 is a well-known panel.
