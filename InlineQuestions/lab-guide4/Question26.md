## Question
26. What is a Sysplex on z/OS?

## Options
Option 1: A single z/OS image
Option 2: A collection of z/OS images that work together as a unit, communicating via XCF signaling and (in Parallel Sysplex) sharing data via the Coupling Facility
Option 3: A backup mechanism
Option 4: A tape silo

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. A Sysplex (System Complex) is the unit of HA + scale on z/OS. Base Sysplex provides XCF communication. Parallel Sysplex adds CF-mediated data sharing, enabling N-way active-active across DB2, CICS, IMS, MQ.

## Incorrect Answer Feedback
The other options are unrelated mainframe terms.
