## Question
17. On z/OS, which filesystem type is the recommended file system for new USS file system mounts in z/OS 2.x?

## Options
Option 1: HFS (Hierarchical File System)
Option 2: zFS (z/OS File System)
Option 3: VTOC
Option 4: NFS

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. zFS is the strategic file system for USS in z/OS 2.x. HFS is legacy and being phased out (IBM has stated zFS is the strategic direction). NFS is for remote mounts; VTOC is the volume table of contents on DASD, not a filesystem type.

## Incorrect Answer Feedback
HFS is legacy. VTOC is dataset metadata. NFS is for cross-system mounts only.
