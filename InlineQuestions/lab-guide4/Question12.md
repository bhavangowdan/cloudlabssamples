## Question
12. On z/OS, what is the difference between DSORG=PS and DSORG=PO?

## Options
Option 1: PS = Physical Sequential (a flat sequential file); PO = Partitioned Organization (a PDS / PDSE with members and a directory)
Option 2: PS = Personal Storage; PO = Permanent Online
Option 3: PS = Public Sector; PO = Production Only
Option 4: They are aliases for the same dataset organization

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. DSORG values: PS = Physical Sequential (think one big flat file), PO = Partitioned Organization (PDS or PDSE — directory + members), VSAM (DSNTYPE=VSAM), and a few others (DA = direct access, IS = indexed sequential historic).

## Incorrect Answer Feedback
The other expansions are not real DSORG meanings.
