## Question
3. Which of the following are valid SMF service states? (Select all that apply)

## Options
Option 1: online
Option 2: maintenance
Option 3: disabled
Option 4: running
Option 5: degraded
Option 6: offline

## Answers
Option 1 : 1
Option 2 : 1
Option 3 : 1
Option 5 : 1
Option 6 : 1

## Correct Answer Feedback
Correct. Valid SMF states: uninitialized, offline, online, degraded, maintenance, disabled, legacy_run. "running" is not an SMF state — that confusion comes from /etc/init.d-style traditional output.

## Incorrect Answer Feedback
"running" is the legacy SysV init phrasing, not SMF.
