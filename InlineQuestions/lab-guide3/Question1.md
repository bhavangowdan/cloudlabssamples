## Question
1. Which two CPU architectures does Oracle Solaris 11 support for production deployment?

## Options
Option 1: SPARC and x86_64
Option 2: SPARC only
Option 3: x86_64 and ARM64
Option 4: POWER and SPARC

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. Solaris 11 supports both SPARC (Oracle SPARC M-series, T-series) and x86_64. The same Solaris userland and kernel features work across both architectures with arch-specific binaries.

## Incorrect Answer Feedback
Solaris does run on x86_64 (Option 2 too narrow). It does not support ARM64 (Option 3) or POWER (Option 4).
