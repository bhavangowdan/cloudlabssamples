## Question
15. What is IPS in Solaris 11?

## Options
Option 1: Intrusion Prevention System
Option 2: Image Packaging System — Solaris 11's network-based, transactional package manager (analogous to apt / yum, with built-in boot environment integration)
Option 3: Internet Protocol Suite
Option 4: Integrated Power Subsystem

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. IPS is Solaris 11's package manager (pkg command). It uses network repositories (publishers), is transactional (failed updates roll back), and integrates with beadm to clone the active boot environment before applying updates.

## Incorrect Answer Feedback
The other expansions are distractors. IPS is the documented package manager term.
