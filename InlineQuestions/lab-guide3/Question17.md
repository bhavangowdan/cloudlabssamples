## Question
17. What is IPMP (IP Multipathing) in Solaris 11?

## Options
Option 1: A storage multipathing tool
Option 2: A network HA mechanism that groups multiple physical NICs to provide failover (and optionally load spreading) for IP traffic
Option 3: A Solaris IPS package
Option 4: A logging facility

## Answers
Option 2 : 1

## Correct Answer Feedback
Correct. IPMP groups physical interfaces into an IPMP group with one or more data IPs and optional test IPs for probe-based failure detection. Failover is automatic on link / probe failure.

## Incorrect Answer Feedback
Storage multipathing is mpathadm / scsi_vhci. IPS is package mgmt. IPMP is purely a network-layer construct.
