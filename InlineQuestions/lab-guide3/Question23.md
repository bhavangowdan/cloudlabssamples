## Question
23. What is Oracle Solaris Cluster?

## Options
Option 1: An HA / cluster product for Solaris that monitors resources (services, IP, storage) and fails them over between nodes on detected failure
Option 2: A SunFire blade frame
Option 3: A new name for Solaris Zones
Option 4: A SAN protocol

## Answers
Option 1 : 1

## Correct Answer Feedback
Correct. Oracle Solaris Cluster (formerly Sun Cluster) is the HA cluster framework. Concepts: Resource Group Manager (RGM), data services (Oracle DB, NFS, etc.), quorum devices, public/private interconnects, fencing.

## Incorrect Answer Feedback
SunFire is a hardware platform. Zones is OS-level partitioning. SAN protocols are FC / iSCSI.
